# Foto della struttura

Finché questa cartella è vuota, il sito usa delle illustrazioni generate al volo.
Per usare le foto vere, salvale qui con questi nomi (JPG, lato lungo circa 1600 px):

| File | Dove appare |
| --- | --- |
| `facciata.jpg` | Fondo del corridoio 3D, galleria |
| `terrazza.jpg` | Camera con Terrazza, galleria, corridoio |
| `camera-balcone.jpg` | Camera con Balcone |
| `camera-twin.jpg` | Camera Twin |
| `camera-singola.jpg` | Camera Singola |
| `bagno.jpg` | Galleria, corridoio |
| `colazione.jpg` | Galleria, corridoio |
| `dettaglio.jpg` | Galleria, corridoio |
| `san-pietro.jpg` | Galleria, corridoio |
| `castel-santangelo.jpg` | Galleria, corridoio |
| `cupola.jpg` | Corridoio |

Puoi cambiare nomi e didascalie in `js/content.js`.
Dopo aver aggiunto le foto, rigenera il file unico con `python3 build.py`.
